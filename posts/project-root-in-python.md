A command-line Python version of the board game Root by Leder Games, focusing on implementing Clockwork bots, following the [Definitive Edition playtest boards](https://boardgamegeek.com/thread/2068034/better-bot-project-24082026-new-catalliancemolecro).

GitHub repo here: [https://github.com/allanwupi/cl-root](https://github.com/allanwupi/cl-root)

This is very much a work in progress. Bots can't craft cards with persistent effects which considerably reduces the amount of rules I need to implement, but unfortunately Root is still a *very* complicated game.

I started this project in the mid-term break of semester 2, 2026. After a few days I scrapped the first version and restarted from scratch. Unfortunately, I used too much CoPilot and currently don't understand how my program works. I think I need to start again...

## Current Features
- Autumn map
- Mechanical Marquise faction (*almost* rules-compliant)
- Items
- Battle mechanic
